# Java Ring：一枚戒指，一杯专属咖啡

1998 年，旧金山的 JavaOne 大会现场，每位参会者领到的伴手礼不是 T 恤，也不是马克杯，而是一枚金属戒指——Java Ring。彼时正值 Java 声势最盛的年代，Sun Microsystems 将这枚戒指视作一次大胆的宣言：未来，人人手上都会戴着一台微型电脑。

但真正让参会者津津乐道的，并不是这个宏大的愿景，而是会场里一个不起眼的“咖啡工厂”展位。

参会者只需先来到一台特殊的终端机前，将戒指贴近读取器，填写一份简单的表单——姓名、公司，以及最重要的一项：喜爱的咖啡口味。这些偏好数据随后会被写入 Java Ring 内部的存储芯片，据说能够保存长达十年之久。

接下来，来到“咖啡工厂”的咖啡机前，贴上戒指，机器便会自动读取其中保存的偏好信息，现场调配出一杯符合个人口味的“Java”——在英语俚语中，Java 本身就有“咖啡”的意思。

Java Ring 内部嵌入了一枚由达拉斯半导体发明的 iButton。它的外形酷似一枚普通纽扣电池，但在金属外壳之下，却封装着一枚集成了微处理器、存储器，乃至 JVM 的芯片。它与外部设备之间通过达拉斯半导体自研的 1-Wire 协议通信——顾名思义，只需一根信号线外加一根地线，便能同时完成数据传输与供电，而这也正是“贴一下就能得到一杯咖啡”这一操作背后的原理。
