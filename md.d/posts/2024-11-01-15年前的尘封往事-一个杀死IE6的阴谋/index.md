# 15年前的尘封往事：一个杀死IE6的阴谋！

1995 年，微软正式发布了 Internet Explorer 浏览器。为了迅速抢占市场的份额，微软就把 IE 浏览器免费捆绑进了 Windows 操作系统里，成为系统默认的浏览器，而这一捆就捆了20多年。诶~不得不说，这个策略真的是太奏效了，IE 就凭借这波恶心的操作，直接干掉了当时的浏览器一哥——网景，宣判封顶。到了 IE6 捆绑 XP 系统发布时，市场份额一度超过了 95%。而 XP 凭借其超长的生命力，也让 IE6 也在浏览器市场上称霸了近 10 年。

时间来到 2009 年，YouTube 的开发团队正被 IE6 折磨得苦不堪言，因为当时大约有 18% 的用户仍然使用 IE6 访问 YouTube 网站，而 YouTube 在 IE6 上经常会发生崩溃的问题。 IE6 显然已经过时了，不符合现代的 Web 标准，缺乏对 CSS 和 JavaScript 的完整支持，让代码维护变得十分困难。支持 IE6 意味着大量的兼容性修复和额外的工作量，严重影响了开发效率。

谷歌是个大公司，想要公开宣布不再支持 IE6，其实并不容易。这需要经过多部门的审批、无数次的会议，还有各种顾虑，担心用户因此流失，影响公司形象 。于是，一群不甘于现状的程序员们决定自己动手，启动了一个杀死 IE6 的阴谋。

他们在没有经过任何正式批准的情况下，悄咪咪地向 YouTube 的代码库添加了一段脚本，这段脚本会在 IE6 用户访问 YouTube 时，在页面顶部展示一条横幅，提示用户：

> 我们将很快停止对您的浏览器的支持，请升级到以下任一更新的浏览器。
> 
> We will be phasing out support for your browser soon. Please upgrade to one of these more modern browsers.

这条横幅还会附带提供包括 Chrome，Firefox，IE8 以及 Opera 在内的几款浏览器的下载链接。

![](img3.png)

这条横幅提示乍看之下挺像那么回事，但仔细看就会发现：上面并没有标注停止支持 IE6 的最后时间，所以嘛其实就是唬唬人的。但他们仍希望，这样的横幅内容可以诓住用户，迫使他们下载包括Chrome 在内的第三方浏览器。当时，谷歌刚刚收购 YouTube 网站，但是 YouTube 的技术代码并没有完全与谷歌融合，也没有办法受谷歌高管的直接管理，这才让 IE6 横幅事件得逞。

结果效果拔群，根据当时的团队 成员克里斯·扎卡里亚斯（Chris Zacharias）提供的数据显示，当这一横幅声明发布的一个月内，使用 IE6 访问 YouTube 的用户份额迅速下降到了 10％，而其他浏览器的用户份额不断上升。

![](img4.png)

虽然这一行动最初是秘密进行的，但在消息被外部媒体报道后，谷歌公司的公关和法律团队也介入了此事。幸运的是，由于这一行动得到了公众和媒体的广泛支持，最终没有引发任何严重的后果。

这个提示上线后，其他公司也纷纷效仿。比如 Facebook 就宣布不再支持 IE6；WordPress 自 3.2 版本起，其后台管理界面不再支持 IE6；咱们的网易新闻也发起了“全网公敌IE6”的活动，都旨在消灭它。

这次一小撮人的阴谋，不仅改变了 YouTube 的用户结构，还推动了整个互联网的迭代更新。随着越来越多的网站开始对 IE6 用户说“不”，微软也不得不有所行动。2011 年3 月，微软推出了一个名为“IE6倒计时”的网站，决定亲自送它最后一程，公开鼓励用户和企业升级到更新的浏览器版本，这也成了压死稻草的最后一只骆驼。

落后就要淘汰是任何时代都不变的真理，随着 IE6 的退场，以及的后续版本的疲软 ，加上Chrome、Firefox 等强劲对手的围剿，微软在 2022 年 6 月停止了对IE的支持，一代浏览器霸主就此陨落 。但它陪伴了无数 80、90一代度过了互联网初兴时代的美好，如今也只能轻叹一声“爷青结！”，或许这也是它最好的归宿。
