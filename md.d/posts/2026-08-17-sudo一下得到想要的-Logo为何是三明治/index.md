# sudo一下得到想要的，Logo为何是三明治

“要说什么才能得到你想要的东西？”——“sudo”。

sudo 是得到美味饼干的“咒语”，这是一个程序员世界中的冷笑话。

但你可能没有注意过，sudo 的官方 Logo，也和吃的有关，是一块带有面孔的三明治。为什么一个负责“提升权限”的 Linux 命令，要和三明治扯上关系？

故事要从一幅著名的 xkcd 漫画（#149《Sandwich》）说起（图 3）。xkcd 是美国漫画家 Randall Munroe 创作的网络漫画，以程序员、数学、科学和互联网文化为主题，以冷幽默和极客梗著称。

一个人让朋友给自己做三明治，被拒绝后，他加上了 sudo，朋友立刻答应了。于是，sudo Logo 的设计中直接采用了三明治这一元素。
