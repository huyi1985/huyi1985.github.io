# 仅用3条CPU指令就能判别闰年？这个算法有点狠

判断闰年，通常绕不开%4、%100 和%400 几个条件分支。常规优化方法是用整除 25 和 16 替代整除 100 和 400，而编译器还会进一步将取模运算优化为乘法与位移运算。

在此基础上，程序员 Falk Hüffner 给出了一个颇为另类的解法：借助 Z3 约束求解器（用于自动寻找满足复杂数学与逻辑约束的解的工具）算出一组“魔数”，把这些判断进一步压缩进乘法与位掩码操作中，最终只用 3 条 CPU 指令完成计算，而且全程无分支。

其优势也相当直接，由于完全避开了条件分支和分支预测带来的开销，性能比传统写法快了约 3.8 倍。这套技巧适用于 0 ≤ y ≤ 102499 范围内的年份。

一个看似简单的“是不是闰年”的问题，最终被压缩成几条底层指令。这大概就是位运算最让程序员着迷的地方吧。
