# 回字有四样写法，Unicode 说：确有其事

孔乙己显出极高兴的样子，将两个指头的长指甲敲着柜台，点头说，“对呀对呀！……回字有四样写法，你知道么？”

于是，我写了一段 Python 代码，去问 Unicode 要答案。

Unicode 为中日韩汉字专门建了一个数据库，叫 **Unihan**（Unicode Han Database）。里面有个叫 `Unihan_Variants.txt` 的文件，用于记录异体字关系，每行三列。只要找到第一列为"回"字码点 `U+56DE`、第二列为 `kSemanticVariant`（表示意思完全一样的异体）的那一行，就能翻出“回”字另外 3 种写法：囘 (U+56D8)、廻 (U+5EFB)、囬 (U+56EC)。

加上本字"回"（`U+56DE`），正好四样：**回、囘、廻、囬**。孔乙己说的四样写法，Unicode 数据库里一条不少。其中"廻"只有 Meyer–Wempe 一本词典作证，算是冷门里的冷门。

这个实验室顺手把四样写法画成了一张复古信息图：

![回字四样写法宣纸风信息图](hui_four_forms.png)

鲁迅写孔乙己，是在嘲笑把学问当敲门砖的穷书生。可一百多年后，那个被众人笑话的"四样写法"，被一个全球字符标准郑重地收进数据库里，编好号、标好出处——几行脚本就把孔乙己憋红脸的答案翻了出来。

回，回，回，回。孔乙己若在今天，应该能喝上一杯温酒。
