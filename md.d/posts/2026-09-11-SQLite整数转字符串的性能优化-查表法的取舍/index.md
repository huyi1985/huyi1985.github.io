# SQLite整数转字符串的性能优化：查表法的取舍

整数转字符串，最直白的写法是反复对 10 取余再除以 10、从低位往高位一位位抠出数字来。SQLite 通过牺牲 200 多字节的存储空间实现了一次处理两位。

源码里有一张表 `sqlite3DigitPairs`，存储着 `00` 到 `99` 这 200 个字符：

转换时，用 `x % 100` 取出末两位，乘以 2 当偏移，直接到表里把对应的那两个字符捞出来，再用一个 `u16` 一次性写进输出缓冲区。

一次两位，求余和除法都直接砍半；查表又省去了（通过 + '0'）逐个生成字符的开销。

拿一点点只读空间，节省一半的整数求余和除法，典型的底层性能优化。

🔚

🏛️ 遗迹地址

- SQLite 源码（amalgamation 版 `sqlite3.c`，搜 `sqlite3DigitPairs` / `sqlite3Int64ToText`）：https://www.sqlite.org/download.html


```c
// SQLite 源码 sqlite3.c
static const union {
  char a[201];
  short int forceAlignment;
} sqlite3DigitPairs = {
  "00010203040506070809"
  "10111213141516171819"
  "20212223242526272829"
  "30313233343536373839"
  "40414243444546474849"
  "50515253545556575859"
  "60616263646566676869"
  "70717273747576777879"
  "80818283848586878889"
  "90919293949596979899"
};
```


```c
// sqlite3Int64ToText() 内部
while( x>=10 ){
  int kk = (x%100)*2;
  *(u16*)(&u.a[i-2]) = *(u16*)&sqlite3DigitPairs.a[kk];
  i -= 2;
  x /= 100;
}
```
