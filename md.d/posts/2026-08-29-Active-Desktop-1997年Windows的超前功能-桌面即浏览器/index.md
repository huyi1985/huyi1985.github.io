# Active Desktop：1997年Windows的超前功能，桌面即浏览器

1997 年，随着 IE 4.0 的发布，微软带来了一项超前的功能：Active Desktop（活动桌面）。微软当时提出了一个大胆的问题：桌面为什么只能放图标和壁纸、网页为什么不能直接嵌入桌面？

天气、股票、新闻，甚至企业内部信息，都应该可以作为“小组件”贴在桌面上，不但位置和大小可以自由调整，而且内容还能自动更新。用户无需打开浏览器，信息就已尽收眼底。这正是微软当年的设想：电脑一开机，互联网上的内容就应该呈现在用户面前——桌面即浏览器。 

不过，这个想法来得太早了。当年的互联网连接速度有限，Web 技术也远没有今天成熟。Active Desktop 占用资源较多，稳定性也不理想，一旦网页加载失败或组件异常，就会出现“无法初始化 Active Desktop”提示。

Active Desktop 最早随着 IE 4.0 进入 Windows 95 和 Windows NT 4.0，随后成为 Windows 98/2000/Me 以及 Windows XP 中的一项功能。

Windows Vista 之后，微软用 Sidebar 取代了 Active Desktop；Windows 7 进一步发展为 Desktop Gadgets。Windows 8 的 Live Tiles，以及今天 Windows 11 的 Widgets，也延续了这个思路：不再让信息藏在应用程序里，而是直接出现在用户面前。
