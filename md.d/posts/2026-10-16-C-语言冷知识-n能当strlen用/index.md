# C 语言冷知识：%n能当strlen用？

在 C 语言里，提到获取字符串长度，大多数人首先想到的是 strlen()。但你可能没想到，printf() 里还藏着一个不太起眼的格式说明符%n。它不负责打印内容，而是把截至当前位置、已经输出的字符数写进一个变量。

如图 1 中的代码所示，printf() 先输出了“Hello World!”这 12 个字符，遇到 %n 后，又把当前累计的输出字符数 12 写入了变量 n。

%n 至少自 1988 年 《K&R The C Programming Language》第 2 版出版发行前就存在了，记录在附录 B。用途应该是文本对齐：比如打印表格时，前面几列的宽度可能不固定，程序员需要知道一行已经输出了多少个字符，才能动态计算需要填充多少空格，以便对齐后续的列。
