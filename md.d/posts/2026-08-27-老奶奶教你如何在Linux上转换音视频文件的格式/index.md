# 老奶奶教你如何在Linux上转换音视频文件的格式

视频中的老奶奶名叫 Andrea Borman，1963 年出生于英国。上学的时候，学校里没有电脑，此后也没有从事过任何与电脑相关的工作。她是在伦敦一家购物中心的网吧里开始学电脑的。按她自己的说法，从第一次接触电脑，到学会收发电子邮件，花了整整一年的时间。

2010 年，她买下了人生中的第一台电脑，一台预装 Windows 7 Starter 的上网本。后来，她注册了 YouTube 频道，把自己学会的电脑操作录下来，分享给大家。

这个频道至今有 300 多个视频，大多数播放量都只有两三千。可唯独有一个例外：一条 9 分多钟、标题为《How To Use FFMPEG On Linux.》的教学视频，播放量达到了 84.1 万，点赞超过 6.8 万。

视频内容很简单，老奶奶分享了一款叫 **MystiQ** 的音视频格式转换软件。MystiQ 其实只是给纯命令行的音视频处理工具 **ffmpeg** 套了一层图形界面。在窗口里选好文件、挑好输出格式，点一下“开始转换”，真正干活的还是后台的 ffmpeg。

视频一开始，老奶奶就做出了一个很有反差感的操作：她打开了终端！自豪地向大家展示：我用的是 Debian Linux。（我第一次见 `neofetch` 这个命令）

然后，她在终端中输入 `ffmpeg`，按下回车。屏幕上立刻涌出大量 ffmpeg 的参数、编解码器和各种选项，占满了整个屏幕。

正当我们以为这位“老将”要开始展示 ffmpeg 纷繁复杂的参数时，她却突然卡壳了，好像忘了自己刚刚输入的这个命令叫什么：**“This is f-f, eh… what's it?”**

她马上把终端窗口最大化，似乎是想让屏幕多显示一些内容，好找到刚才那行命令。

她终于想起来了：**“…m-p-e-g.”**

然后开始随意滚动终端窗口，似乎是在掩饰刚才的尴尬。接着她坦言，在 Linux 里有很多基于终端的程序，没有图形界面……在终端里做文件格式转换这件事很复杂，要摆弄的东西太多，**“I can't do it.”**

“但这个办法要容易得多。”于是她开始演示 MystiQ 的用法。真是个有趣的老奶奶。

这让我想起了姥爷。

那是流氓软件猖獗的年代，各种弹窗、各种“助手”，还有同时跑着的好几个杀毒软件。光开机就要花上几分钟，电脑也卡得要死。

姥爷其实只需要上上网、看看新闻、玩玩“连连看”。每次重装 Windows XP，要不了几天，电脑就又会被各种流氓软件塞满。于是我干脆给他装了个**红旗 Linux**。

有一天，我无意间翻到了电脑桌上的一个笔记本。里面记录着：

`cd` 是做什么的，`ls` 是做什么的，每个参数又是控制什么的……

我猜他应该是自己去书店翻 Linux 的书了。**边看，边记录，没买。**
