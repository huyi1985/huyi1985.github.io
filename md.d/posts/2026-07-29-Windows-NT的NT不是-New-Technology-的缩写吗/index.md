# Windows NT的NT不是“New Technology”的缩写吗？

Windows NT 中的 NT，长期以来都被认为是 New Technology（新技术） 的缩写，但事实并非如此。

2003 年，Windows NT 原始开发团队成员证实：NT 最初并不代表什么“新技术”，而是 Intel 一款 RISC 处理器 i860 的内部代号：N10，读作 N-Ten。

1988 年底，Windows NT 项目启动时，团队最初瞄准的平台正是 Intel i860。然而这颗处理器当时尚未问世，工程师只能在 i860 模拟器上开发和调试代码。既然每天都围着 N-Ten 工作，项目便顺势取名为 NT——一个再普通不过的内部工程代号。

后来，为了对外宣传，微软才赋予 NT 一个更讨喜的解释——New Technology。这个名字一直流传至今，也让许多人误以为这就是 NT 两个字母真正的含义。

至于那颗让 NT 得名的处理器，却没能活下来。Intel 曾希望 i860 成为取代 x86 的下一代架构，但由于开发延期、实际性能不及预期，这场豪赌最终以失败告终，i860 也在数年后停产。而那个原本只是工程代号的 NT，却一直留在 Windows 的历史中。
