# Linux 中还有哆啦A梦中出现过的蒸汽机车

还记得哆啦A梦中那些出现过蒸汽机车（**SL**，Steam Locomotive）的故事吗？
![[Pasted image 20240725203357.png]]

记得有个道具叫“蒸气火车烟囱”。只要戴上它就可以像 **SL** 火车那样强而有力。
![[Pasted image 20240725204231.png]]

在 Linux 中，有一个命令就叫作 `sl`，名字正是取自"Steam Locomotive"的缩写。

在终端中输入 `sl` 并按下回车键后时，屏幕上就会显示一个动画：一辆蒸汽机车从屏幕的一侧驶向另一侧。

![[Pasted image 20240725204635.png]]
https://github.com/mtoyoda/sl/blob/master/demo.gif?raw=true
`sl` 完全是一个为了娱乐而存在的小程序，并没有实际的功能。最初设计的目的是纠正用户在终端中的拼写错误——错把 `ls` 输入成了 `sl`。
