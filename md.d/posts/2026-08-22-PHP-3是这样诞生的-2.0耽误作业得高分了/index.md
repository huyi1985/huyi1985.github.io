# PHP 3是这样诞生的：2.0耽误作业得高分了

1997 年，以色列理工学院的两名学生 Andi Gutmans 和 Zeev Suraski，正在折腾期末作业：给电子商务网站加入购物车功能，以便获得额外的加分。他们选中了当时还很年轻的 PHP 2.0。教授却不太看好，觉得 PHP 还太年轻，没经过多少实战检验。对于购物车这种业务逻辑复杂的项目，风险不小。

二人还是决定试试，不过很快就发现，教授说得对。PHP 2.0 虽然方便，但不够健壮，程序一复杂，底层解析器的局限就暴露了。只好换一种语言了吧？不，他们二人刚学完编译原理，手里拿到了一把锤子，看什么都像钉子。

于是，购物车先放一边，干脆把 PHP 的解析器重写一遍吧。他们联系了 PHP 的创造者 Rasmus Lerdorf，三人开始从底层重新设计解析器……

1998 年 6 月，PHP 3.0 正式发布。PHP 3 还加入了面向对象编程的功能——两位同学大概又刚学完面向对象课程吧，手里又多了一把锤子。PHP 3 发布后不久，二人又开始了第二次核心重写，创造了后来著名的 Zend Engine。这个名字正是 Zeev 和 Andi，两人名字的组合。Zend Engine 于 1999 年年中首次推出，后来成为 PHP 4 的核心。

Andi 后来回忆，最让他兴奋的或许不是技术本身，而是 PHP 降低了 Web 开发的门槛。在 1990 年代，开发网站还是一件更偏向专业人士的事情，而 PHP 的出现，让更多普通技术人员甚至非计算机专业人士也有了参与 Web 开发的机会。

这不和今天 AI 辅助编程，让“不会写代码的人也能做软件”很像吗？
