# 用蒙特卡洛法+泊松分布探究麻将天和的概率

今天我们来聊一聊，怎么用一点编程+概率知识，估算出麻将“天和”和（胡）牌的可能性大小。

用电脑反复进行“掷骰子”一样的随机模拟，由此来估算一个现象出现的可能性，就是所谓的**蒙特卡洛法**。应用该方法，只需要记住其中有几次“刚抓完 14 张牌就能和牌”，即天和的次数，再除以总的模拟次数，就差不多能估出天和的概率了。

从 136 张麻将牌中随机抓牌，本质上与从 1～136 个数中随机选 14 个数（无放回地选）没有区别，判断能否和牌也有现成的代码库。这两部分稍加组合，即可写出一个模拟程序。

运行结果如图2，参考代码见图3。相关笔记@：mahjong一个会打麻将🀄️的Python库🐍

可以看到天和的概率大概是百万分之几。运气好时甚至还有可能是七小对的天和。

那这辈子能打出天和的可能性怎么算呢？其实知道了天和的概率后，再有一个参数就能估计出来，即还需要知道一辈子打了多少局牌。只需要大概估计一下即可，比如 1 万局、5 万局、10 万局……

因为天和的概率非常小，而打牌的局数又很多，所以可以利用一种叫作**泊松分布**的规律，将天和的概率和局数相乘，得到一个称作拉姆达（λ）的结果，这个λ就是麻将生涯中最有可能打出天和的次数。比如假设天和的概率是百万分之4，打过10万局牌，那么打出天和的概率大概是32.97%，此时λ = 0.4。

## 什么是“天和”？

简单说，天和就是：**庄家第一轮抓完牌，不用摸、不靠吃碰，直接就能胡**。

没有比这更帅的开局了。但这也意味着，你的14张初始手牌，必须恰好就是一副完整的胡牌牌型。按常理来说，这概率低到几乎可以忽略不计。

但到底有多低？我们试试看能不能用代码模拟出个大概的数字。

---

## 蒙特卡洛法：靠“重复试试”解决问题

不想去推复杂的排列组合公式？可以的，那就用**蒙特卡洛方法**。

这方法说白了就是“用大量的随机尝试来逼近结果”。

我们模拟几百万次发牌，每次都随机洗牌、发庄家的14张初始牌，看看其中有多少次能直接胡。

别小看这“土方法”，只要次数够多，出来的结果还是很靠谱的。

## 一辈子有机会遇到一次天和吗？

这时候就要用点概率知识了。  
假设你一辈子打了 **10 万局麻将**，每局天和的概率是 0.000012，那么至少遇到一次的概率是多少？

直接套公式也行：

python

CopyEdit

`p = 0.000012 n = 100_000 prob = 1 - (1 - p) ** n print(f"一生中至少遇到一次天和的概率 ≈ {prob:.2%}")`

大概结果是：**70% 左右**。  
所以说，别不信邪——搓得够多，真的有机会见识一次传说中的“开门胡”。

---

## 引入泊松分布，看得更清楚

如果你稍微学过点概率论，可能记得：

> 当事件很稀有（p很小），但重复次数很多（n很大）时，二项分布可以用**泊松分布**来近似。

我们这里的 λ（lambda）就是 n × p，也就是你一辈子“期望”遇到的天和次数。

用泊松分布算一下：

python

CopyEdit

`import math  λ = 100_000 * 0.000012  # 1.2 prob = 1 - math.exp(-λ) print(f"泊松分布估算，一生中至少一次天和的概率 ≈ {prob:.2%}")`

结果依旧差不多是 **70%**，说明这个模型还是挺靠谱的。
