## 小写转大写

对32按位取反，生成掩码（mask）

```
~ 0 0 1 0 0 0 0 0  (32)
-------------------
  1 1 0 1 1 1 1 1  (mask)
```

将字符 a 与掩码做按位与（AND）运算，，即可转换成 A

```
  0 1 1 0 0 0 0 1  (97 = 'a')
& 1 1 0 1 1 1 1 1  (mask)
-------------------
  0 1 0 0 0 0 0 1  (65 = 'A')
```

如果已经是大写字母 A，则值不变

```
  0 1 0 0 0 0 0 1  (65 = 'A')
& 1 1 0 1 1 1 1 1  (mask)
-------------------
  0 1 0 0 0 0 0 1  (65 = 'A')
```

## 大写转小写

将字符 A 与32做按位或（OR）运算，即可转换成 a

```
  0 1 0 0 0 0 0 1  (65 = 'A')
| 0 0 1 0 0 0 0 0  (32)
-------------------
  0 1 1 0 0 0 0 1  (97 = 'a')
```

如果已经是小写字母 a，则值不变：

```
  0 1 1 0 0 0 0 1  (97 = 'a')
| 0 0 1 0 0 0 0 0  (32)
-------------------
  0 1 1 0 0 0 0 1  (97 = 'a')
```

## 翻转大小写字母

使用按位异或（XOR）和 32 进行运算，即可翻转字母 A 的大小写

```
  0 1 1 0 0 0 0 1  (97 = 'a')
^ 0 0 1 0 0 0 0 0  (32)
-------------------
  0 1 0 0 0 0 0 1  (65 = 'A')
  
  0 1 0 0 0 0 0 1  (65 = 'A')
^ 0 0 1 0 0 0 0 0  (32)
-------------------
  0 1 1 0 0 0 0 1  (97 = 'a')
```
