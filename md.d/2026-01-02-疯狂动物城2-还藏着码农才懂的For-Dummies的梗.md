# 《疯狂动物城2》还藏着码农才懂的For Dummies的梗

在电影《疯狂动物城 2》中，**朱迪**和**尼克**因为办砸了走私集团的案件，被牛局长送去参加一个类似“拍档关系建设班”的课程。课后，朱迪递给尼克一本书《Partnership for Dummy》。

![](/assets/6px56m.webp)

如果你是技术圈的人，看到这个封面应该会瞬间会心一笑吧。没错，这配色，这字体，不就是知名的**入门级 IT 图书系列**之一——**For Dummies** 系列的经典风格吗？

For Dummies 系列起源于上世纪 90 年代个人电脑普及时期，最早的作品是《DOS For Dummies》。该系列图书目标直白：让完全没有技术背景的人也能理解计算机和信息技术。

![](/assets/wbvrxy.webp)

For Dummies 系列在技术圈里常被称为“第 0 本书”，虽然无法替代深入的专业资料，但在消除技术恐惧、建立基本概念方面，功劳不小。

不过我觉得，为了避开专业术语而使用大量比喻的 For Dummies 系列，有时候反而比那些堆满冷冰冰术语的书还难读。主要还是自己词汇量不够，生动活泼的句子里到处都是生词，而术语就那么几个词。

其实，For Dummies 并**不只限于**计算机类主题，还涵盖生活、商务、心理学等主题。

另外，我忍不住想：如果去翻翻 O'Reilly 系列的封面，能不能凑出一部《疯狂动物城》？兔子、狐狸、水牛……封面上应该都有吧。
