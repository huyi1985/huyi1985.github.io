# 核心 Python 开发者竟被停职 3 个月，“罪名”之一是“太三俗了”

2024 年 8 月， Python 软件基金会出大事了。Tim Peters，一位为 Python 贡献了 20 余年聪明才智的核心开发者竟被判罚停职 3 个月。

![](/assets/y14n4o.png)

Peters 荣获过 Python 软件基金会 2017 年杰出服务奖。自上世纪 90 年代初期就开始从事 Python pre-release 0.9.1 版本的开发。截至 2024 年，他的贡献量仍排名第 11 位。

他发明了 Timsort 排序算法，从 Python 2.3 到 3.10 的每个版本都在使用该算法，V8 JavaScript 引擎中也可以看到该算法的身影。他还为 Python 标准库贡献了 doctest 和 timeit 这两个模块。

Peters 还撰写过《Python 之禅》(The Zen of Python)，旨在阐述 Python 的设计哲学。我们只需要输入 `import this` 这样 1 行代码就可以静心“参禅”了：

![](/assets/fx2thr.png)

从 2001 年到 2014 年，Peters 积极参与 Python 邮件列表的讨论，更是 Stack Overflow 上排名数一数二的贡献者。

总之，Tim Peters 是一位为 Python 做出诸多贡献的开发者。

那就很难想象为什么 Python 软件基金会要暂停他的职务了。

Python 软件基金会列举了 Peters 的十大“罪状”。
![](/assets/wzu36n.png)

“罪状”之一是，

> Using potentially offensive language or slurs, in one case even calling an SNL skit from the 1970s using the same slur “genuinely funny”, which shows a lack of empathy towards other community members.
> 
> 使用了冒犯或诋毁他人的语言，甚至宣称 1970 年代的《周六夜现场》短剧“真的很有趣”，这表明该人对其他社区成员缺乏同理心。

仅仅因为觉得《周六夜现场》中的一个短剧很有趣就缺乏同理心了？到底是哪个短剧呢？

> 《**周六夜现场**》（Saturday Night Live，缩写 SNL）是美国一档于周六深夜时段直播的喜剧小品类综艺节目

这个短剧是 1979 年由丹·艾克罗伊德 (Dan Aykroyd) 和简·科廷 (Jane Curtin) 主演的“Point, Counter-Point”，里面有这样一句台词，

![](/assets/bws1l7.png)

“slut”确实是不文明用语，但 Peters 为什么“明知故犯”还要提及这一段呢。据说是因为有一个名为“slut”的 Python 包（因其名称已被审查），而 Peters 不想说出作为包名的这个词，故而引用了这段短剧暗指这个包。

姑且不去评论其他“罪名”，光看这一条，确实感觉是荒唐荒诞荒谬。

若以 `"nsfw" site:pypi.org` 为关键词搜索 Python 官方的软件包仓库，就会发现，也不是那么圣洁嘛。比如，https://pypi.org/project/pythonmommy/ 这个包，里面不也净是不文明用语吗。

> nsfw，Not Safe For Work，泛指不适合在公众场所中浏览的内容

![](/assets/4ogat5.png)

https://pypi.org/ 里感觉少说有几十上百个包封装了各种低俗的 Restful API，有的还用上了 asyncio，体现了在技术上的追求。RESTful API 本来是为 Programmatic Web（通过程序自动化与网络资源交互）服务的，这么一看，最终“惠及”的还是人。我 `nsfw.download()` 可以，但你不能三俗。
