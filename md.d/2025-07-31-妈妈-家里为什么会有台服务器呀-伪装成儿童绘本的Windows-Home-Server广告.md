# 妈妈，家里为什么会有台服务器呀？——伪装成儿童绘本的Windows Home Server广告

Windows Home Server 是微软于 2007 年推出的一款专为家庭用户设计的操作系统，旨在集中管理家庭内多台电脑中的文件，方便家庭成员共享照片、音乐等内容。

![](/assets/x9h6gi.webp)

有趣的是，微软竟将 Windows Home Server 的宣传广告编成了一本儿童读物，从娃娃抓起，向孩子们解释为什么爸爸要买台服务器放到家里，装上了服务器有什么好处。

![](/assets/ih6sak.webp)

这本绘本中充满了些许奇特的情节：

爸爸妈妈深爱彼此，于是爸爸决定送给妈妈一份特别的礼物——一台家用服务器（这开局就比欧·亨利出人意料，都不用卖祖传金表了）；

![](/assets/92on6y.webp)
![](/assets/zsk1m8.webp)

有了服务器后，“你”就可以和远方穿着花格子衫的“老冒”（smells like bark）叔叔分享照片（突然想到《疯狂动物城》里兔子警官的爸妈）；

![](/assets/2yk84o.webp)


“你”被小伙伴嘲笑，表面上是因为他们认为服务器只能放在办公室，实际上则是嫉妒“你”有个好爸爸为家里添置了服务器，他们久久地凝视着“你”家服务器上的磁盘指示灯，闪呀闪，闪呀闪……

![](/assets/khym45.webp)
![](/assets/rbj8ge.webp)

尽管宣传意图明显且略显用力，但读起来依然颇具趣味。

随着云存储和家用 NAS 的普及，Windows Home Server 的市场逐渐萎缩，微软最终于 2013 年停止开发，将相关功能整合进 Windows Server Essentials 产品线。

🔚

![](/assets/801xfo.png)

----


> 该系统通过名为驱动器扩展（Drive Extender）的创新技术，将多块硬盘合并为一个存储池，提供了数据冗余功能。驱动器扩展类似于现在的软件定义存储，结合了文件级冗余和存储池管理的特点，具备分布式文件系统的部分理念。2011 年发布的第二版虽然界面更加美观，但取消了备受欢迎的驱动器扩展功能，引发用户不满。

> 与此同时，NAS 服务器开始出现在市场上，它“开箱即用”，提供了便捷的界面，可以快速创建磁盘存储。然而，宽带互联网的普及和 Dropbox 等云服务的发展使得 WHS 对大多数用户来说变得毫无用处。没错，数据量开始增长，但现在它们不再存储在本地，而是存储在远程服务器上。
