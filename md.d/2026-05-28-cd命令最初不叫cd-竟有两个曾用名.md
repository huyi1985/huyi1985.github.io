# cd命令最初不叫cd，竟有两个曾用名

刚毕业找工作那会，面试官问我：“你熟悉 Linux 吗？常用哪些命令？”

我想了想：`ls`、`cd`……

然后，就没有然后了……

在面试官看来，`cd` 大概是 Unix 世界里最“不值一提”的命令之一了吧。既不做计算，也不处理文本，也不能用于观察系统的各项指标，功能简单到四个字就能概括：**切换目录**。

可十几年后，当开始翻看 Unix 早期源码时，才无意发现这个每天都要敲几十上百次的命令，背后竟是一段延续数年的**名字变迁史**：`cd` 命令最初不叫 `cd`，还有过两个曾用名。

## 第一个曾用名：ch

时间要回到 1968 年。那一年，Bell 实验室寄予厚望的 Multics 项目宣告失败。

无所事事的 Ken Thompson 和 Dennis Ritchie 等年轻工程师，开始“折腾”一台被闲置的 PDP-7 小型机。他们最初只是想在这台机器上运行一个叫作《Space Travel》的游戏。但事情很快偏离了玩游戏的初衷。为了让程序顺利运行，他们不得不从零开始搭建工具链与系统环境，这些为了支撑游戏运行而不断拼凑出来的基础设施，最终逐渐生长为一个完整的操作系统雏形——Unix 的原始版本。

初代 Unix 已经具备了今天人们熟悉的层级目录结构。为了进入某个目录，或者更严谨地说“切换当前工作目录”，Ken Thompson 设计了一个极其朴素的命令：`ch`（是 h，不是 d）。

`ch` 应该是 “**CH**ange directory“ 的缩写，意为“切换目录”。可以从如下视频中看到 Unix V0 上的 `ch` 命令是如何使用的：

也就是说，今天我们熟悉的 `cd` 命令，在最初诞生时，其实叫作 `ch`。

## 第二个曾用名：chdir

别看 `ch` 的功能极其简单，其背后却依赖一个名为 `chdir` 的系统调用。所谓“系统调用”，就是用户程序和操作系统内核沟通的通道。像“切换当前目录”这样看似基础的操作，本质上仍需要通过内核提供的能力才能完成，而这个能力正是 `chdir`。

或许只是为了让命名在拼写上更加统一，在 Unix V1 的开发阶段（约 1971 年），`ch` 被重命名为 `chdir`。至于这一变化究竟出于何种动机，随着时间流逝，细节已逐渐模糊。

甚至连 Unix 的缔造者之一 Dennis Ritchie 在后来回忆时也坦言，对这一改名的原因已经记不清了。他只留下过一句略带随意的说明：

> Incidentally, _chdir_ was spelled _ch_; why this was expanded when we went to the PDP-11 I don't remember.

“顺便一提，`chdir` 最初写作 `ch`；至于为什么在迁移到 PDP-11 时被扩展成完整形式，我已经不记得了。”

![Dennis Ritchie（站立）与 Ken Thompson（坐着），在 Bell 实验室于一台 DEC PDP-11 计算机前合影](/assets/ofj82s.webp)

不管原因如何，这个变化让 `cd` 的命名链条中，多出了**第二个曾用名**：`chdir`。

## // cd for "chdir"

时间一晃来到 **1976 年**。

随着 Unix 从研究项目逐步走向商业软件，其版权与授权限制也开始变得复杂。在这一背景下，加州大学伯克利分校率先发展出自己的 Unix 变体版本，也就是后来著名的 BSD 分支。

彼时年轻的 Bill Joy 正在主导 **BSD Unix** 的早期开发工作。作为最活跃的系统开发者之一，他对 shell 的改造与重写不断推进 Unix 用户接口的演化。在这一过程中，他留下的**一行注释**，使 `cd` 作为 `chdir` 的简写第一次被明确记录下来：

```c
/*
 * UC berkeley shell
 *
 * Modified by Bill Joy Oct 14, 1976
 *
 *  library "lib"
 *  cd for "chdir"
```

这里清楚写着：

```
cd for "chdir"
```

这说明，`cd` 这个名字，是 Bill Joy 在 BSD shell 时代“发明”的。或许只是一个极其“工程化”的选择：更短、更顺手，少敲几个字符。

从那一刻起，`cd` 逐渐从 BSD 世界扩散开来，并开始成为事实上的标准命名。

与此同时，Bell 实验室的“正统 Unix”也在持续演进。Unix V6 大约出现在 **1975 年**，而随后更具影响力的 Unix V7 则在 **1979 年**发布。Bell 实验室与 BSD 之间的设计影响也开始相互渗透，在 Unix V7 中，`cd` 作为 `chdir` 的别名被正式引入。

---

到了今天，`cd` 已成为切换目录的统一表达（MS-DOS 上切换目录也用 `cd`），那些早期的命名分歧也早已淡出历史，以至于 `cd` 看起来从未有过其他名字。至于那条从 `ch → chdir → cd` 的路径，又还有多少人会记得呢？
