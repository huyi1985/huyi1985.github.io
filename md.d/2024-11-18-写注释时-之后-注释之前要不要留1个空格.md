# 写注释时，//之后、注释之前要不要留1个空格？

有人表示不需要留空格，有人强烈表示必须留1个空格！



连红色警戒 3 的长官 Anatoly Cherdenko，都对此发表了意见。他怒吼道“SPACE”，坚决要求保留空格。



还有人表示就没写注释，No comment——无可奉告！

```go
// No comment
func Foo() {
	fmt.Println("Hello")
}
```

> No comment 既可理解为“没有注释”，也可理解成惯用语“无可奉告”

你的习惯是？
