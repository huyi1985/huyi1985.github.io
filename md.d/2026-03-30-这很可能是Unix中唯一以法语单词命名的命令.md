# 这很可能是Unix中唯一以法语单词命名的命令

在 Unix 的世界里，我们早已习惯了那种简洁、甚至略显隐晦的、以英语缩写命名的命令——`ls`、`cp`、`mv`、`rm`。然而，在这个由英语主导的技术王国中，却悄然存在着一位优雅的“法语访客”：`apropos`。

1979 年，在加州大学伯克利分校，Bill Joy（后来 Sun Microsystems 的联合创始人）为 BSD 3 系统创建了这个命令。与大多数 Unix 命令不同，`apropos` 保留了完整的法语词形，源自短语 “à propos”，意为“关于”“就……而言”或“恰如其分”。

这个词几乎是对该命令功能的精确描述：在 man 手册页中，查找与关键词“相关”的内容。

比如，要想查找**和网络相关的**命令，就可以输入：

![](/assets/i1o6qw.png)

```bash
$ apropos network
s3cmd (1)            - tool for managing Amazon S3 storage space and Amazon CloudFront content delivery network
byteorder (3)        - convert values between host and network byte order
ctstat (8)           - unified linux network statistics
……
```

这一命名选择，似乎带着明显的时代气息。20 世纪 70 年代的伯克利校园，比新泽西的贝尔实验室更具国际化氛围，而 Joy 本人也拥有广泛的文学兴趣。在一个偏爱 `grep`、`awk` 这类极简命名的世界里，选择一个 7 字母的法语词，本身就体现了一种难得的语言意识与文化审美。

`apropos` 在 Unix 命名体系中几乎是孤例。虽然像 `vis`（visible）、`locale`、`route` 等命令的名字同样源自法语，但它们早已融入英语语境，成为英语的“固有”词汇。只有 `apropos`，依然保留着鲜明的法语身份。

> `vis` 用于把**不可打印字符**（比如换行、制表符、控制字符）转成**可见的转义形式**；`locale` 用于显示或变更**语言与区域设置**；`route` 用于操作**内核路由表**。

有趣的是，该命令的早期源代码中，有一处单词拼写错误。

![](/assets/ij1w6w.png)

现代版本已经修正了这个错误：

```bash
$ apropos food
food: nothing appropriate.
```

顺带一提，除了创办了 Sun Microsystems 公司，Bill Joy 还是 **vi 编辑器**的作者以及 **BSD UNIX** 的设计者之一，被《Fortune》杂志誉为**互联网时代的爱迪生**（The Edison of the Internet）。

![Bill Joy 互联网时代的爱迪生](/assets/qdm3pi.webp)

他还在 BSD Unix 的 TCP 实现中独立发明了“Hi，TCP 连接，你死了么？”的 TCP Keepalive 机制。

----


还有一个小小的历史趣味：在早期 BSD-3 的源代码中，这个命令曾长期带着一个拼写错误——“nothing apropriate”。在一个专门用于查找“恰当”内容的工具里出现这样的失误，不免让人会心一笑。

47 年过去了，当 Research Unix 的命名传统始终坚持英语路径，当绝大多数 Unix 命令依旧是简短的缩写，`apropos` 依然活跃在每一个现代 Unix 系统中。它不仅被 POSIX 标准采纳，还被 GDB、LLDB 等工具借用，成为“按关键词搜索”的通用术语。

这个法语命令的存在，仿佛是一种微妙的提醒：技术世界并不必然单一。命名不仅是功能的标签，也是思想的表达。在效率至上的 Unix 哲学中，`apropos` 展示了另一种可能——优雅、精确，而且恰如其分。正如它的本义：perfectly apropos。

---

**后记**：下次当你在终端输入 `apropos password` 时，不妨想一想这个穿越了半个世纪的法语词，也想一想 1979 年伯克利校园里，那位做出这一命名选择的年轻程序员。在技术的演进中，有些东西比代码更持久——那就是对语言之美的坚持。
